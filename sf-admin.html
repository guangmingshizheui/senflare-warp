优选端点

MASQUE 配置

H2 走 TCP 可优选端点，H3 走 QUIC 仅可使用账号分配的 IP 端点，H2 + H3 每个端点各出一对节点
拥塞控制算法，决定弱网下的传输效率与稳定性
是否转发隧道内 UDP 流量（ 游戏 / 语音 / QUIC 应用 ），H2/H3 均支持，建议保持开启
节点内 DNS 解析列表，用于隧道内域名解析
TLS 握手时对外展示的域名。端点不校验 SNI，被过滤网络封堵时可换大厂域名（ 如 Apple / Microsoft ）

项目介绍PROJECT

Senflare Warp 是 基于 Cloudflare WARP 的 MASQUE 自建节点方案 —— 在 Cloudflare Workers + D1 免费额度内自建 WARP 账号池，一键注册、多账号管理、订阅分发，无需自备服务器。

  • MASQUE —— H2（HTTP/2 over TCP，可优选、抗过滤）+ H3（HTTP/3 over QUIC）双形态直连，IPv4/IPv6 端点全兼容。
  • 一键注册 —— 面板内直接注册 WARP MASQUE 账号，自动生成标准 SEC1 密钥并入库，开箱即用。
  • 端点优选 —— 浏览器实测 Cloudflare 端点延迟与连通，优质端点一键写入订阅。
  • 多端订阅 —— 一套链接按客户端自动分发 masque://（Shadowrocket）/ Clash YAML / sing-box JSON，多格式开箱即用。
  • 更多功能 —— 自己探索，懒得打字。
